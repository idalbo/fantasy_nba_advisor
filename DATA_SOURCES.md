# Data Sources

The following data sources are used in the Fantasy NBA Advisor application:

1. **Basketball Reference**: statistical data for NBA players based on the 2024-2025 season.
    - Website: [https://www.basketball-reference.com/](https://www.basketball-reference.com/leagues/NBA_2025_per_game.html)
2. **The Ringer top 100 NBA Players**: expert analysis and rankings of the top 100 NBA players. Both statistical data and expert analysis are used.
    - Website: [https://nbarankings.theringer.com/](https://nbarankings.theringer.com/)
3. **HoopsHype**: 2025-2026 NBA player rankings and analysis.
    - Website: [https://eu.hoopshype.com/story/sports/nba/2025/10/03/nba-ranking-the-top-100-players-for-2025-26/86477672007/](https://eu.hoopshype.com/story/sports/nba/2025/10/03/nba-ranking-the-top-100-players-for-2025-26/86477672007/)
4. **sport ws**: fantasy NBA scoring system, specifically this is what is used in my case:
    - Scoring Format: Custom
    - FTs Made: 1.5
    - FTs Attempted: -0.5
    - 2Ps Made: 2.5
    - 2Ps Attempted: -0.5
    - 3Ps Made: 3.5
    - 3Ps Attempted: -0.5
    - Offensive Rebounds: 1.0
    - Defensive Rebounds: 1.0
    - Assists: 1.0
    - Blocks: 1.0
    - Steals: 1.0
    - Turnovers: -1.0
    - Win: 0.0
    - Loss: 0.0
